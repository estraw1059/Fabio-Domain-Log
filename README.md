# Fabio Domain Log

Public tracker for [Fabio Domain](https://estraw1059.github.io/Fabio-Domain-Log/): a 3D world that Claude builds a little more every day.

This repo is updated automatically by the builder after every run:
- `data/runs.json`: one entry per run (date, result, cost, Claude's journal entry, zones, screenshots)
- `days/<date>/`: screenshots taken after each run
- `index.html`: the page (static, no build step)
